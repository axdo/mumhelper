# 妈妈帮手（MumHelper）需求分析

> 版本：v0.3（极简版）
> 历史版本：v0.1 母婴记录 MVP（喂养/尿布/睡眠/统计）；v0.2 移除妈妈分娩档案；**v0.3 大幅精简，只保留喂奶起止时间记录**（尿布、睡眠、统计图表、宝宝档案全部移除）

## 1. 产品定位

记录喂奶开始时间与结束时间、展示当天记录的单页小工具（PWA，手机浏览器优先，可安装到主屏幕、离线可用）。数据存浏览器本地 IndexedDB，不出设备。

## 2. 功能需求（全部范围）

### 2.1 喂奶记录
- 字段：开始时间、结束时间（datetime-local 选择，默认分别为一小时前与当前时间）
- 校验：结束时间必须晚于开始时间，否则禁止保存并提示
- 保存成功有 toast 提示

### 2.2 今日记录展示
- 展示当天所有喂奶记录：开始–结束时间、时长，按开始时间倒序
- 顶部汇总：今日共 N 次、总时长
- 支持删除（需确认）

## 3. 非功能需求

- 数据存于浏览器本地（IndexedDB / Dexie），刷新、离线不丢
- 移动优先响应式，手机竖屏单手可用
- PWA：可安装、离线可用（需 HTTPS 环境）
- 记录带 `id` / `createdAt` / `updatedAt`，为将来可能的云同步预留

## 4. 已移除的功能（决策记录）

| 功能 | 移除版本 | 原因 |
|---|---|---|
| 妈妈分娩档案 | v0.2 | 对标医院专业系统后自研价值不大 |
| 尿布/睡眠记录、统计图表、宝宝档案 | v0.3 | 用户决定聚焦极简：只记喂奶起止时间 |

## 5. 数据模型

- `feedings`：`id`、`startTime`、`endTime`（均 epoch ms）、`createdAt`、`updatedAt`

Dexie 数据库版本演进：v1 初版五表 → v2 移除 mother 表 → v3 只保留 feedings 表。
